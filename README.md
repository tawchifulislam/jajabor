# WayNama

> সারা বিশ্ব হয়ে যায় আমার নিজের ঘর
> খোলা আকাশের নিচে সবাই যাযাবর

A personal log of the places I want to go - and the ones I've already been.

WayNama (পথের-গল্প) started as one developer's private travel wishlist: a place to keep photos, routes, and notes for the corners of Bangladesh worth visiting. It grew into something anyone can add to - log a place you've personally visited, and track your own trail of "want to go" and "been there" across the country's districts.

No reviews, no bookings, no ads. Just an honest, shared list - built one journey at a time.

---

Built with Next.js, MongoDB, Better Auth, and Cloudinary.
Live at [WayNama.vercel.app](https://waynama.vercel.app)
